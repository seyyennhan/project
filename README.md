# Neon Snake

A small, self-contained browser arcade game built with HTML, CSS, and JavaScript. No build step or dependencies required.

## Play

Open `index.html` in a browser, then select **Start game**. Guide the snake to the food and avoid the walls and your own tail.

- **Move:** Arrow keys or WASD
- **Pause / resume:** Space
- **Start / restart:** Enter or the on-screen button
- Touch devices have on-screen direction buttons.

Your best score is saved in your browser using local storage.
